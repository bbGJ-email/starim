# Checklist
- [x] 实名认证接口按根目录 API 文档调用，并正确处理匹配、不匹配、无身份证、频率限制等响应。
- [x] 未实名用户只收到提醒，不被阻断基础聊天、好友、朋友圈和公众号使用。
- [x] 用户资料接口只返回实名状态和脱敏信息，不返回完整身份证号。
- [x] SMTP 配置通过 env 加载，源码和可提交文件中不包含邮箱授权码。
- [x] 已绑定邮箱用户可以通过邮箱验证码重置密码。
- [x] 邮箱验证码具备过期时间、频率限制和用途隔离。
- [x] 密码重置后旧 Token 失效或敏感接口拒绝旧 Token。
- [x] 前端公众号列表、注册、详情、订阅/取消订阅入口可用。
- [x] 个人资料页展示实名状态、未实名提醒、邮箱绑定入口。
- [x] 登录页或登录流程提供邮箱找回密码入口。
- [x] JWT 密钥没有硬编码 fallback，缺少必要密钥时服务拒绝启动。
- [x] 敏感词过滤覆盖消息、朋友圈和公众号内容，并对词库加载失败有容错。
- [x] IP 风险评分/临时封禁覆盖限流、登录失败、验证码滥用，且能自动过期。
- [x] 消息撤回受可配置时效窗口限制。
- [x] 文件上传具备本地类型白名单、大小限制和可选本地 ClamAV 扫描开关。
- [x] 后端配置加载检查通过。
- [x] 前端构建或可用替代校验通过，若环境异常需记录具体原因。
- [x] lint/typecheck 已执行；若项目缺少工具需记录具体原因。
- [x] Git 检查确认 `.env`、SMTP 密码、身份证号等敏感信息未进入提交内容。
